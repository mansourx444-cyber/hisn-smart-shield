# ٤. القيمة المضافة — لماذا «حِصن» مختلف

## ٤.١ المشكلة في جملة
المحتال لا يخترق الهاتف، **يخدع صاحبه**: رسالة برابط مزيف، أو مكالمة تطلب رمز التحقق. والحلول الحالية إما تحذّر بعد فوات الأوان، أو تحظر بدون شرح فيتجاهلها المستخدم.

## ٤.٢ الحل في جملة
«حِصن» يتدخل **في لحظة الخطر نفسها**، أثناء المكالمة وقبل فتح الرابط، ويقول للمستخدم بلغته **ما الخطر، ولماذا اشتبه، وما الخطوة الآمنة**، والقرار يبقى له.

## ٤.٤ رسالة العرض في ٣٠ ثانية (Elevator pitch)
> «كل يوم يُخدع شخص برسالة أو مكالمة تطلب رمز التحقق. «حِصن» مساعد ذكي يسمع ويقرأ معك، ولما المحتال يطلب الرمز أثناء المكالمة، يحذرك فورًا ويشرح لك ليش، والمكالمة ما زالت مستمرة. ويربط الجهات الرسمية بالناس، فأي حيلة جديدة تنشرها الشرطة أو البنك توصل لكل هاتف خلال ثوانٍ.»
